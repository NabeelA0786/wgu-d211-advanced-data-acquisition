# D211 – Advanced Data Acquisition

**WGU Master of Science in Data Analytics**

## Overview
Demonstrated advanced SQL skills by extracting, transforming, and analyzing data from relational databases. Combined telecom customer data with U.S. Census income data to answer business questions.

## Datasets
- Telecom customer churn dataset
- ACS 5-Year Income Estimates by ZIP code (U.S. Census Bureau, 2023)

## What Was Done
- Wrote complex SQL queries with multi-table joins
- Used aggregations, filters, and subqueries to extract business insights
- Built a Tableau dashboard to visualize query results
- Documented data sourcing, transformation logic, and findings

## Tools
`SQL` · `Tableau` · `Python` · `Pandas`
